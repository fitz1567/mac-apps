Using it

Where does it work?

Anywhere you can type a commit message. On GitHub pull requests and GitLab merge requests it starts from the page’s title, branch and labels and fills the squash-merge box. Anywhere else, click the text box first, then open Commit Builder and click Fill on Page, or press Enter to copy the message.

What are Conventional Commits?

A simple format for commit messages, “type(scope): summary”, that tools use to write changelogs and pick version numbers. See conventionalcommits.org.

Fill on Page didn’t work

On GitHub, click Squash and merge first so the message box is showing. Chrome doesn’t let extensions change some pages (like the Chrome Web Store); copy the message there instead.

Can I add my own types?

Yes, in Settings: add types like “security” and the scopes you use most.

Privacy

Does it send my code or messages anywhere?

No. It makes no network requests, and everything it keeps stays in your browser.
