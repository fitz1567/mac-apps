Table Copy privacy policy

Effective October 2, 2026

Table Copy is a Chrome extension by Kevin Fitzgerald. It does not collect your data. There is no account, no analytics and no server of ours: what you save stays in your browser on this computer.

What it keeps on your computer

  • Your settings (line breaks, number style, which tables to list)
  • With Pro: rows you add to a collection, kept only until the browser closes
  • Your license key, if you buy Pro

This lives in the browser's own extension storage. Removing the extension deletes it.

Network

Table Copy never sends the pages or tables you copy anywhere. The only network request is checking a Pro license key with Lemon Squeezy, when you activate it and every two weeks.

Pro purchases

Pro is sold by Lemon Squeezy, which handles the payment and emails your license key. Lemon Squeezy's own privacy policy covers that purchase. When you activate a key, Table Copy sends the key and a device label (such as "Table Copy on macOS") to Lemon Squeezy's license server to check it, and checks it again about every two weeks.

Permissions

  • activeTab: Reads the tables in the tab only when the user clicks the toolbar button (or presses the shortcut), and only that tab.
  • scripting: Runs one script in that tab to read its tables' cells and to draw a highlight box over the table the user points at. It changes nothing on the page.
  • storage: Keeps the user's settings on this computer and, with Pro, the rows collected from several pages of a table until the browser closes (session storage).
  • api.lemonsqueezy.com (asked only when you activate a key): to check your Pro license key.

Sharing and selling

Nothing is sold or shared. No data is used for advertising, credit or lending.

Children

Table Copy isn't directed at children under 13 and collects nothing from anyone.
