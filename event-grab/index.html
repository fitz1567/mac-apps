Event Grab privacy policy

Effective October 6, 2026

Event Grab is a Chrome extension by Kevin Fitzgerald. It does not collect your data. There is no account, no analytics and no server of ours: what you save stays in your browser on this computer.

What it keeps on your computer

  • Your settings (default time zone, event length, reminders)
  • With Pro: the last 50 events you added (title, time, place, description and the page link)
  • Your license key, if you buy Pro

This lives in the browser's own extension storage. Removing the extension deletes it.

Network

Event Grab never sends the page or your events anywhere and never reads your calendar. “Open in Google Calendar” opens Google’s own new-event page in a tab, filled in, for you to save. The only other network request is checking a Pro license key with Gumroad, when you activate it and every two weeks.

Pro purchases

Pro is sold by Gumroad, which handles the payment and emails your license key. Gumroad's own privacy policy covers that purchase. When you activate a key, Event Grab sends the key and Event Grab's Gumroad product ID to Gumroad's license server (api.gumroad.com) to check it, and checks it again about every two weeks. Nothing else is sent.

Permissions

  • activeTab: Reads the page only when the user clicks the toolbar button, to find the event they selected.
  • scripting: Runs a one-time function in that tab to get the selected text and the page's schema.org event data.
  • storage: Keeps the user's settings and, with Pro, a list of the last 50 events they added, on this computer.
  • api.gumroad.com (asked only when you activate a key): to check your Pro license key.

Sharing and selling

Nothing is sold or shared. No data is used for advertising, credit or lending.

Children

Event Grab isn't directed at children under 13 and collects nothing from anyone.
