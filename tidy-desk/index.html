Tidy Desk privacy policy

Effective October 6, 2026

Tidy Desk is a Chrome extension by Kevin Fitzgerald. It does not collect your data. There is no account, no analytics and no server of ours: what you save stays in your browser on this computer.

What it keeps on your computer

  • Backups of your bookmark tree (titles, addresses, folders, dates), compressed: the latest one, or the last 10 with Pro
  • The Bookmarks tool's settings (which duplicate to keep, the monthly reminder)
  • Your download rules (file types, sites, name patterns, folders, rename templates)
  • The last 20 downloads the Downloads tool sorted: file name, the folder it went to and which rule did it (no addresses)
  • Your license key, if you buy Pro

This lives in the browser's own extension storage. Removing the extension deletes it.

Network

Tidy Desk never sends your bookmarks, downloads or rules to us or anyone else: no account, no server, no analytics. If you use the Pro dead-link check, it asks each bookmarked site for its page once (no cookies, no referrer). Downloads makes no network requests. Checking a Pro license key contacts Gumroad when you activate it and every two weeks.

Pro purchases

Pro is sold by Gumroad, which handles the payment and emails your license key. Gumroad's own privacy policy covers that purchase. When you activate a key, Tidy Desk sends the key and Tidy Desk's Gumroad product ID to Gumroad's license server (api.gumroad.com) to check it, and checks it again about every two weeks. Nothing else is sent.

Permissions

  • storage: Keeps each tool's settings and data on this computer: the Bookmarks tool's compressed backups of the bookmark tree (so changes can be undone) and its settings; the Downloads tool's rules and the names of the last 20 files it sorted; the Pro license.
  • unlimitedStorage: The Bookmarks tool keeps up to 10 compressed backups of the whole bookmark tree (Pro); for people with tens of thousands of bookmarks that can pass Chrome's default 10 MB, and a backup that fails to save would mean no undo. No install warning.
  • sidePanel: Lets the user keep Tidy Desk open in Chrome's side panel, for example to watch downloads being sorted.
  • alarms: The Bookmarks tool's Pro monthly reminder, only when the user turns it on: a badge on the toolbar button once a month.
  • bookmarks (optional): Never granted at install. Asked the first time the user opens the Bookmarks tool (“Bookmarks needs access to your bookmarks, to clean them up”, Allow / Not now). Reads the bookmark tree to find duplicates, empty folders and same-name folders, and removes, moves or sorts bookmarks only after the user ticks them and clicks Apply; also restores backups.
  • downloads (optional): Never granted at install. Asked the first time the user opens the Downloads tool. Used only to suggest a folder and file name inside the Downloads folder when a download starts (chrome.downloads.onDeterminingFilename): it reads the new download's file name, address, the page it came from and its file type to apply the user's rules. It never opens, moves, deletes or reads the contents of files.
  • api.gumroad.com (asked only when you activate a key): to check your Pro license key.

Sharing and selling

Nothing is sold or shared. No data is used for advertising, credit or lending.

Children

Tidy Desk isn't directed at children under 13 and collects nothing from anyone.
