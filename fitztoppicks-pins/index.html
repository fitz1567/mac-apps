FitzTopPicks Pins privacy policy

Last updated October 3, 2026

FitzTopPicks Pins is a private tool used only by Kevin Fitzgerald, owner of the FitzTopPicks shop on Etsy. It runs on his own computer and posts pins of his own Etsy listings to his own Pinterest boards. It is not offered to the public, and no one else signs in to it.

What it reads from Pinterest

  • Kevin's own Pinterest account name, so it knows which account it's signed in to
  • Kevin's own boards and the pins it has posted, so it doesn't post the same pin twice and can put each pin on the right board

It doesn't read any other Pinterest user's pins, boards, profile or activity, and it doesn't read analytics about other people.

What it writes to Pinterest

Pins of FitzTopPicks' Etsy listings (image, title, description, alt text and a link to the listing), and boards to hold them, all on Kevin's own account.

Where data is kept

The Pinterest sign-in token and a list of pins already posted are stored only on Kevin's computer. Nothing is sent to any other server, and there are no ads, analytics or trackers.

Sharing and selling

Nothing about any Pinterest user is collected, so nothing is sold or shared.

Removing access

Kevin can disconnect the tool at any time in Pinterest's settings (Security and logins › Apps), which ends its access.

Changes

If this policy changes, this page will show the new date.
