Dev Bench privacy policy

Effective October 6, 2026

Dev Bench is a Microsoft Edge extension by Kevin Fitzgerald. It does not collect your data. There is no account, no analytics and no server of ours: what you save stays in your browser on this computer.

What it keeps on your computer

  • Each tool's settings and the tool you used last
  • Decode & convert: your pinned tools and, with Pro and history turned on, recent results per converter (never secrets or keys)
  • JSON viewer: your theme and last JSONPath query; with Pro, the sites you turned on for auto-formatting (site names only) and the JSON snippets you saved
  • Compare text: the two texts you're comparing and your options; with Pro, the comparisons you save
  • Regex tester and Cron schedules: the pattern or expression you're working on, and your saved patterns (with sample text and test cases) and schedules
  • Fake data: your current schema and output settings; with Pro, the schemas you save
  • Fill forms: your settings (data locale, test card, seed); with Pro, per-site presets (field = value) and your data lists
  • Your license key, if you buy Pro

This lives in the browser's own extension storage. Removing the extension deletes it.

Network

Dev Bench never sends anything you paste, open, view or generate anywhere: no account, no server, no analytics, and every tool works offline. It reads a tab only when you click its button there (or, with Pro, on sites you turned on for JSON auto-formatting), and never submits a form. The only network request is checking a Pro license key with Gumroad, when you activate it and every two weeks.

Pro purchases

Pro is sold by Gumroad, which handles the payment and emails your license key. Gumroad's own privacy policy covers that purchase. When you activate a key, Dev Bench sends the key and Dev Bench's Gumroad product ID to Gumroad's license server (api.gumroad.com) to check it, and checks it again about every two weeks. Nothing else is sent.

Permissions

  • activeTab: When the user clicks the toolbar button (or presses its shortcut, or the Pro fill shortcut) on a tab, two tools can use that one tab: JSON viewer reads the page's text once to show its JSON, and Fill forms reads the form fields and fills them with test values. Only that tab, only until it navigates.
  • scripting: Runs a one-time function in that tab: JSON viewer gets the page's text (the JSON response, or the selected text); Fill forms reads the form's fields (type, name, label, limits) and sets the test values. With Pro, JSON viewer also registers its auto-format script for each site the user turned on, and removes it when they turn the site off.
  • storage: Keeps each tool's data on this computer: the last tool used and pinned converters (and, with Pro and history on, recent converter results, never keys or secrets); JSON viewer settings, auto-format sites and saved snippets; the texts being compared and saved comparisons; the pattern and cron expression being edited and the saved libraries; the fake data schema and saved schemas; form fill settings, site presets and data lists; and the Pro license.
  • sidePanel: Lets the user keep Dev Bench open in Edge's side panel, next to the code, docs, API console or form they are working on.
  • optional:https://*/* and http://*/*: Never asked for as a whole and never at install. Pro only: when the user clicks 'Always format <site>' in JSON viewer, Edge asks for access to that one site (for example https://api.example.com/*), so JSON responses there open formatted without a click. Removing the site in Dev Bench's settings gives the access back.
  • optional:https://api.gumroad.com/*: Asked for only when the user activates a Pro license key, to check the key.
  • web_accessible_resources (tools/json/viewer.html): Not a permission. On the sites the user turned on for auto-formatting (Pro), JSON viewer's page is shown in a frame in place of the raw JSON text. use_dynamic_url is on, so pages can't use it to detect the extension.
  • api.gumroad.com (asked only when you activate a key): to check your Pro license key.

Sharing and selling

Nothing is sold or shared. No data is used for advertising, credit or lending.

Children

Dev Bench isn't directed at children under 13 and collects nothing from anyone.
