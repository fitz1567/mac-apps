Dev Bench support

Offline developer tools: JWT and Base64 decoder, JSON viewer, text diff, regex and cron testers, fake data, form filler.

The 7 tools

  • Decode & convert: JWT decoder, Base64, URL encoding, timestamps, UUIDs and hashes, offline, so tokens and keys never go to a website. Free: JWT decoder with expiry, Base64 and Base64URL (text and files), URL encode, decode and parse, timestamps in any time zone, UUID v4 and checks, SHA-256 of text or a file with checksum compare. Pro: JWT signature checks with secrets, PEM keys, certificates and JWK Sets, HMAC, SHA-1/384/512 and MD5 (text and files), UUID v7, JSON ↔ YAML, number bases, HTML entities, string escaping, case and lorem ipsum, history and pinned tools.
  • JSON viewer: A fast JSON viewer for the tab you’re on, a file or a paste: tree, search, exact big numbers and copyable paths. Free: the tree, pretty and raw views for huge files, exact big numbers, search, copy a JS, JSONPath or jq path, paste, open or drop files. Pro: JSONPath queries with filters, compare two documents, CSV export, sorted keys, saved snippets, auto-format on sites you choose.
  • Compare text: Compare two texts line by line and word by word; nothing is uploaded. Free: line and word compare with highlights, folded context, next and previous change, open or drop files, up to 200 KB per side. Pro: character highlights, side by side in a full tab, ignore whitespace, case or a pattern, JSON-aware compare, a merge view, .diff and HTML export, saved comparisons, 5 MB per side.
  • Regex tester: Test regular expressions: live matches, groups, a replace preview and plain-English errors. Free: the tester with highlights, numbered and named groups, the replace preview, a syntax sheet and 5 saved patterns. Pro: an unlimited library with tags and search, test cases per pattern, plain-English explanations, code for JavaScript, Python, Go, PHP and Java, JSON import and export.
  • Cron schedules: Explain, build and test cron expressions, with the next runs in your time zone and daylight-saving changes marked. Free: standard 5-field cron explained in plain English, errors, the next 5 runs, a builder and a syntax sheet. Pro: Quartz, AWS EventBridge, GitHub Actions, Kubernetes and systemd, conversion between them, 50 runs in any time zone, a saved library, deploy snippets.
  • Fake data: Realistic but clearly fake test data from a schema you build, as CSV, JSON or SQL; the same seed makes the same file. Free: 1 table, 1,000 rows and 10 columns, 33 column types, templates, a live preview, CSV and JSON. Pro: up to 1,000,000 rows, 60 columns, 8 linked tables, unique and empty values, SQL for PostgreSQL, MySQL and SQLite, JSON Lines and Markdown, six more locales, saved schemas, data lists for Fill forms.
  • Fill forms: Fill the form you’re testing with realistic fake data in one click: names, example.com emails, test cards, dates. Free: fill the main form, US English data, skip filled fields, a repeatable seed, every value shown. Pro: site presets, your own data lists (or Fake data’s), UK, Spanish, French and German data, fill every form on the page, a keyboard shortcut.

Install

Add it from your browser's store (the Chrome Web Store, or Microsoft Edge Add-ons and Firefox Add-ons where it's listed), then pin it. In Chrome or Edge: click the puzzle-piece (Extensions) icon in the toolbar and the pin next to Dev Bench. In Firefox: click the Extensions button and choose “Pin to Toolbar”.
