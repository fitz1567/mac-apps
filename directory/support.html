Getting started

Why does Directory ask for access to my home folder?

Mac App Store apps can open only the folders you choose. Give access to your home folder once and Directory can open everything in it; add other disks in Settings > Safety.

Can Directory replace the Finder?

You can use it for everything you do with files. macOS keeps the Finder for the desktop and some system tasks, so it stays running in the background.

Safety

Can I get something back?

Yes. Deleting always moves items to the Trash, and Edit > Undo reverses any change, including copies and moves. Replacing a file moves the old one to the Trash first.

Why can’t I change some folders?

Directory never changes macOS’s own folders, your disks themselves or the insides of apps, where one changed file can break things. You can allow changes inside your Library folder in Settings > Safety.

Are copies checked?

Yes: every copy is compared with the original (SHA-256). You can turn that off in Settings > Safety for faster copies.

Directory Pro

What does Pro add?

Dual panes and workspaces, the shelf, batch rename, folder sizes and the disk map, the duplicate finder, zip archives, checksums, Git badges, Vim keys and the Shortcuts actions. It’s a one-time purchase, with no subscription.

Purchases

How do I get a refund?

Apple handles App Store refunds. Request one at reportaproblem.apple.com.

Do I have to pay again on another Mac?

No. Sign in to the App Store with the same Apple Account on your other Mac and download it from your purchases.
