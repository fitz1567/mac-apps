Getting started

Does Directory need Full Disk Access?

No, it’s optional. Directory opens your home folder, disks and Applications right away. macOS keeps a few places private (Mail, Messages, Safari, other apps’ data and Time Machine backups) and asks once before an app opens Desktop, Documents or Downloads. To see everything without being asked, open System Settings › Privacy & Security › Full Disk Access and turn on Directory (Directory’s Settings › Safety has a button that goes there).

Can Directory replace the Finder?

You can use it for everything you do with files. macOS keeps the Finder for the desktop and some system tasks, so it stays running in the background.

What can I ask?

Finding (“big videos in Downloads”, “the lease from July”), acting (“move every PDF with invoice in the name into Taxes 2026”, “zip the Novel folder”) and explaining (“what’s taking space in Downloads?”). Every change is shown as a plan first, and nothing happens until you click Apply.

Safety

Can I get something back?

Yes. Deleting always moves items to the Trash, and Edit › Undo reverses any change, including copies, moves and a whole plan. Replacing a file moves the old one to the Trash first.

Why can’t I change some folders?

Directory never changes macOS’s own folders, your disks themselves or the insides of apps, where one changed file can break things, even with Full Disk Access. You can allow changes inside your Library folder in Settings › Safety.

Are copies checked?

Yes: every copy is compared with the original (SHA-256). You can turn that off in Settings › Safety for faster copies.

Directory Pro

What’s free, and what does Pro add?

Free: the map with folder sizes, Ask, “What’s Taking Space?”, plans with undo, the list drawer, previews and Shortcuts. Pro adds split view and workspaces, batch rename, the duplicate finder, zip archives, the shelf, checksums, Git badges, Vim keys, Coding Leftovers (clear rebuildable build folders in old projects), Cold Storage (move old projects to an external drive, checked file by file) and Shrink Big Videos (smaller HEVC copies, originals to the Trash only when you approve). It’s a one-time purchase, with no subscription.

Where do I enter my license key?

Choose Directory › License… in the menu bar (or open Directory Pro), paste the key from your Gumroad receipt and click Activate.

How do I get updates?

Directory checks for updates on its own; you can also choose Directory › Check for Updates…. Updates are free.

Purchases

How do I get a refund?

Gumroad handles payment. Reply to your Gumroad receipt or email help@fitztoppicks.com.

Do I have to pay again on another Mac?

No. One license key works on up to 3 of your Macs. Download the app again from your Gumroad receipt or library and enter the same key.
