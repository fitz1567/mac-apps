Selectsum privacy policy

Effective November 5, 2026

Selectsum is a Firefox add-on by Kevin Fitzgerald. It does not collect your data. There is no account, no ads, no analytics or tracking of any kind, and no server of ours: what you save stays in Firefox on this computer.

What it keeps on your computer

  • Number settings (decimal style, currency sign)
  • Sites where Selectsum is turned off
  • Totals you save (Pro): date, site, page title, the numbers and their totals (Save isn't offered in private windows)
  • Your license key, if you buy Pro, and the buyer email address Gumroad returns when it checks the key
  • Fingerprints (SHA-256 hashes, not the keys themselves) of license keys already activated in this browser, so entering a key again doesn't use another of its 3 places

This lives in the browser's own extension storage. Removing the extension deletes it.

Network

Selectsum has no server. Selected text is read only on your computer, only to find numbers, and is never sent anywhere. The only network request is checking a Pro license key with Gumroad, when you activate it and every two weeks.

Private windows

Firefox runs add-ons in private windows only if you allow it (about:addons › Selectsum › Run in Private Windows). Then the totals work there too, but nothing is saved from a private window: the Save button isn't offered and the toolbar button can't turn the site on or off, so no page you visit privately is written down.

Pro purchases

Pro is sold by Gumroad, which handles the payment and emails your license key. Gumroad's own privacy policy covers that purchase. When you activate a key, Selectsum sends the key and Selectsum's Gumroad product ID to Gumroad's license server (api.gumroad.com) to check it, and checks it again about every two weeks. Nothing else is sent. Firefox asks you first, and lists it as optional data collection (“authentication information”): if you say no, nothing is sent and the free features keep working.

Permissions

  • storage: Keeps the user's number settings, the sites they turned Selectsum off for, and (Pro) the totals they chose to save and the license, in the browser on this computer.
  • <all_urls>: The content script reads the text the user selects (only when they select it, only to find numbers) and shows the totals next to it, so it has to run on every site. Nothing is sent anywhere or kept unless the user clicks Save (Pro), which stays on this computer.
  • api.gumroad.com (asked only when you activate a key): to check your Pro license key.

Sharing and selling

Nothing is sold or shared. No data is used for advertising, credit or lending.

Children

Selectsum isn't directed at children under 13 and collects nothing from anyone.
