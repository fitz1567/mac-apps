Stripbeam privacy policy

Effective November 5, 2026

Stripbeam is a Firefox add-on by Kevin Fitzgerald. It does not collect your data. There is no account, no ads, no analytics or tracking of any kind, and no server of ours: what you save stays in Firefox on this computer.

What it keeps on your computer

  • The strip's settings
  • Which sites the strip is on or off for, and their preset (Pro); a choice made in a private window lasts only for that page and isn't saved
  • Saved presets (Pro)
  • Your license key, if you buy Pro, and the buyer email address Gumroad returns when it checks the key
  • Fingerprints (SHA-256 hashes, not the keys themselves) of license keys already activated in this browser, so entering a key again doesn't use another of its 3 places

This lives in the browser's own extension storage. Removing the extension deletes it.

Network

Stripbeam has no server and never reads the pages it runs on. The only network request is checking a Pro license key with Gumroad, when you activate it and every two weeks.

Private windows

Firefox runs add-ons in private windows only if you allow it (about:addons › Stripbeam › Run in Private Windows). Then the strip works there too, but turning it on or off in a private window (from the toolbar button or Alt+Shift+R) lasts only for that page, and the toolbar button can't give the site a preset, so no site you visit privately is written down. Sites you turned on in a normal window keep their strip in private windows.

Pro purchases

Pro is sold by Gumroad, which handles the payment and emails your license key. Gumroad's own privacy policy covers that purchase. When you activate a key, Stripbeam sends the key and Stripbeam's Gumroad product ID to Gumroad's license server (api.gumroad.com) to check it, and checks it again about every two weeks. Nothing else is sent. Firefox asks you first, and lists it as optional data collection (“authentication information”): if you say no, nothing is sent and the free features keep working.

Permissions

  • storage: Keeps the strip's settings, the sites it is on or off for, and (Pro) saved presets and the license, in the browser on this computer.
  • <all_urls>: The content script draws the reading strip over whatever page the user is reading, so it has to run on every site. It never reads page text or sends anything; it only adds a click-through overlay (and, if the user picks one, a font style).
  • api.gumroad.com (asked only when you activate a key): to check your Pro license key.

Sharing and selling

Nothing is sold or shared. No data is used for advertising, credit or lending.

Children

Stripbeam isn't directed at children under 13 and collects nothing from anyone.
