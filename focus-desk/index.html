Focus Desk privacy policy

Effective October 6, 2026

Focus Desk is a Chrome extension by Kevin Fitzgerald. It does not collect your data. There is no account, no analytics and no server of ours: what you save stays in your browser on this computer.

What it keeps on your computer

  • Your saved sessions, automatic snapshots and recently closed windows: the address and title of each tab, tab group names and colors
  • Your window layouts: window positions and sizes, monitor sizes, and the address and title of each tab in them
  • Sleep tabs’ settings, never-sleep list and per-site timers (site patterns you type); while the browser is open, when each tab was last used (cleared when it closes)
  • Site names (like youtube.com) with the volume level you chose to remember for them (Pro)
  • The sites on your block and allow lists, your schedules, the current focus session (end time and what you said you’re working on), and daily counts of sessions, focus minutes and breaks
  • Break settings and routines, how many breaks you took, skipped or snoozed each day (kept 400 days), the current break timer
  • Your license key, if you buy Pro

This lives in the browser's own extension storage. Removing the extension deletes it.

Network

Focus Desk has no server and sends nothing about you, your tabs or the sites you visit anywhere: no account, no analytics. Tab sound is processed in Chrome on your computer and never recorded; Chrome does the site blocking from your list. The only network request is checking a Pro license key with Gumroad, when you activate it and every two weeks.

Pro purchases

Pro is sold by Gumroad, which handles the payment and emails your license key. Gumroad's own privacy policy covers that purchase. When you activate a key, Focus Desk sends the key and Focus Desk's Gumroad product ID to Gumroad's license server (api.gumroad.com) to check it, and checks it again about every two weeks. Nothing else is sent.

Permissions

  • activeTab: Gives Focus Desk access to the current tab only when the user clicks its toolbar button (or presses its shortcut), so Tab volume can change that one tab’s sound and Sleep tabs can show and change that site’s rule. No other tab, and nothing before the click.
  • storage: Keeps each tool’s settings and the user’s data on this computer: saved sessions and snapshots (tab titles and addresses), window layouts, the never-sleep list and timers, remembered volume levels per site (Pro), block lists, schedules and focus stats, break settings and daily break counts, and the Pro license.
  • sidePanel: Lets the user keep Focus Desk open in Chrome’s side panel, for example to watch a focus session or switch sessions while working.
  • alarms: Wakes the background worker on a timer: Sessions’ snapshot every few minutes, Sleep tabs’ one-minute check, Block sites’ session and schedule edges, Breaks’ reminder time.
  • idle: Breaks counts only the time the user is actually using the computer: chrome.idle says when there’s been no keyboard or mouse for a while, or the screen is locked. Nothing about what the user does is read or stored.
  • offscreen: Tab volume opens one hidden extension page (reason USER_MEDIA) while a tab’s volume isn’t 100%: it plays that tab’s sound back through Web Audio at the chosen level. It closes when no tab is changed.
  • unlimitedStorage: Sessions keeps up to 48 snapshots of every window’s tabs (Pro) plus saved sessions, which can pass Chrome’s default 10 MB for people with hundreds of tabs; without it a snapshot could fail to save.
  • system.display: Window layouts reads the monitors’ sizes and work areas, so a layout restores each window on the right monitor and snaps fill the right screen. No install warning.
  • declarativeNetRequestWithHostAccess: Block sites asks Chrome to block the listed sites during a focus session or schedule with declarativeNetRequest rules; Chrome does the blocking, Focus Desk never sees the pages. With this permission the rules apply only on sites the user gave access to (below), so there’s no install warning.
  • tabs (optional): Never granted at install. Asked the first time the user opens Sessions, Sleep tabs or Window layouts (“… needs access to the titles and addresses of your tabs”, Allow / Not now): Sessions saves them, Sleep tabs matches them against the never-sleep list and timers, Window layouts saves which pages each window shows. Tab volume’s Pro list asks for it on its own button.
  • tabGroups (optional): Asked with tabs when Sessions first opens, so saved sessions keep tab group names and colors (restored with Pro).
  • tabCapture (optional): Never granted at install (it would show “Read and change all your data on all websites”). Asked the first time the user opens Tab volume, then used only after they move the slider on the tab they clicked Focus Desk on. Chrome shows its sharing icon on that tab while its volume isn’t 100%; nothing is recorded.
  • notifications (optional): Asked the first time the user opens Breaks, to show the break reminder with Start break and Snooze buttons.
  • *://*/* (optional): Never granted at install. Block sites asks for the sites on the user’s list (only those, e.g. youtube.com) when a focus session starts or in its settings, because Chrome applies blocking rules only on sites the extension may access; an allow-list (Pro) needs every site, asked when it’s used. Used only to block those sites and show Focus Desk’s calm blocked page there; pages are never read. Listed and removable on the settings page.
  • https://api.gumroad.com/* (optional): Asked for only when the user activates a Pro license key, to check the key.
  • api.gumroad.com (asked only when you activate a key): to check your Pro license key.

Sharing and selling

Nothing is sold or shared. No data is used for advertising, credit or lending.

Children

Focus Desk isn't directed at children under 13 and collects nothing from anyone.
