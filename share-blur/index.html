Share Blur privacy policy

Effective October 6, 2026

Share Blur is a Chrome extension by Kevin Fitzgerald. It does not collect your data. There is no account, no analytics and no server of ours: what you save stays in your browser on this computer.

What it keeps on your computer

  • Your settings and pattern rules
  • Saved blurs: the site address, the page path and a CSS selector (or text position) for each blurred part; never the blurred text
  • Your license key, if you buy Pro

This lives in the browser's own extension storage. Removing the extension deletes it.

Network

Share Blur has no server and sends nothing anywhere. It reads page text only on your computer, to find what your rules should blur. The only network request is checking a Pro license key with Gumroad, when you activate it and every two weeks.

Pro purchases

Pro is sold by Gumroad, which handles the payment and emails your license key. Gumroad's own privacy policy covers that purchase. When you activate a key, Share Blur sends the key and Share Blur's Gumroad product ID to Gumroad's license server (api.gumroad.com) to check it, and checks it again about every two weeks. Nothing else is sent.

Permissions

  • activeTab: When the user clicks the toolbar button (or presses its shortcut), Share Blur gets access to that one tab so it can blur what the user picks there. No other tab, and only after the click.
  • scripting: Injects the blurring script into the tab the user clicked the button on. With Pro auto-blur, registers that script for the sites the user chose (and removes it when the site is removed).
  • storage: Keeps the user's settings, pattern rules and saved blurs (CSS selectors and text positions per site, never the blurred text) on this computer.
  • *://*/* (optional): Declared as optional only, never granted at install. When a Pro user turns on auto-blur for a site, Chrome asks for access to that one site so blurs can be applied as its pages load. Turning auto-blur off gives the access back.
  • https://api.gumroad.com/* (optional): Asked for only when the user activates a Pro license key, to check the key.
  • api.gumroad.com (asked only when you activate a key): to check your Pro license key.

Sharing and selling

Nothing is sold or shared. No data is used for advertising, credit or lending.

Children

Share Blur isn't directed at children under 13 and collects nothing from anyone.
