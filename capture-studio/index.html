Capture Studio privacy policy

Effective October 6, 2026

Capture Studio is a Chrome extension by Kevin Fitzgerald. It does not collect your data. There is no account, no analytics and no server of ours: what you save stays in your browser on this computer.

What it keeps on your computer

  • Your screenshots and their annotations (the latest one, or the last 20 with Pro), in the extension's local database on this computer, with the page's title and address
  • Your bug reports, screenshots and annotations (the current one, or the last 100 with Pro), including the address of the page you captured
  • Your last 8 screenshots for mockups and the address of the page each came from, your mockup settings and presets
  • Your code-image look settings and presets; the code you're editing, in session storage that Chrome clears when it closes
  • Saved blurs: the site address, the page path and a CSS selector (or text position) for each blurred part, never the blurred text; your blur settings and pattern rules
  • Your pins and comments, with the element each is on (a CSS selector and a little of its text), the address and title of each page you review, report screenshots (a crop around each pin), and with Pro project names, your reviewer name and the sites you turned auto-show on for
  • Your recording settings (recordings are kept in Chrome only until you save them as a file)
  • Your text-grab settings, how many free grabs you used today, and with Pro your last 50 grabs (text, a small picture of the area, page title and site name, date)
  • Your license key, if you buy Pro

This lives in the browser's own extension storage. Removing the extension deletes it.

Network

Capture Studio never uploads your screenshots, recordings, text, reports, pins, code or the pages you capture: no account, no analytics, no server. Text is read on your computer by the OCR engine inside the extension; images, videos and PDFs are made in your browser and saved as files you choose. The only network request is checking a Pro license key with Gumroad, when you activate it and every two weeks.

Pro purchases

Pro is sold by Gumroad, which handles the payment and emails your license key. Gumroad's own privacy policy covers that purchase. When you activate a key, Capture Studio sends the key and Capture Studio's Gumroad product ID to Gumroad's license server (api.gumroad.com) to check it, and checks it again about every two weeks. Nothing else is sent.

Permissions

  • activeTab: Gives Capture Studio access to the current tab only when the user clicks its toolbar button (or presses one of its shortcuts), so the tools can work on that one page: take a screenshot of it (Screenshot, Bug report, Mockup, Grab text, Review pins' report), record it (Record tab), read the code selected on it (Code image), or blur or pin things on it (Blur, Review pins). No other tab, and nothing before the click.
  • scripting: Adds a tool's script to that tab after the user starts it there: Screenshot scrolls the page for a full-page capture (hiding sticky headers, then putting the scroll back) and shows the drag-to-select layer; Grab text shows its draw-a-box layer; Code image reads the selected text once; Blur blurs what the user clicks (and puts saved blurs back before a capture); Review pins draws its pins in a closed shadow root and scrolls to each pin for the report; Record tab draws click highlights and the countdown (Pro) while recording. With Pro, it also registers Blur's and Review pins' scripts for the sites the user chose and Chrome granted.
  • storage: Keeps each tool's settings and the user's work on this computer: report templates, mockup presets and code-image looks, saved blurs (selectors and text positions, never the blurred text), pins and comments with the reviewed page addresses, the free daily grab count and (Pro) the last 50 grabs, recording settings, and the Pro license.
  • sidePanel: Lets the user keep Capture Studio open in Chrome's side panel next to the page, for example to blur things, pin comments or watch a recording's timer while working.
  • offscreen: Record tab opens one hidden extension page (reason USER_MEDIA) while a recording runs: it records the tab with MediaRecorder, plays the tab's sound back so the user still hears it, and mixes in the microphone or webcam if the user turned them on. It closes when the recording has been handed to the “Recording ready” page.
  • unlimitedStorage: Screenshots (Screenshot keeps the last 20 with Pro, often several MB each for full pages), bug reports with their screenshots (the last 100 with Pro) and review-report screenshots are kept in the extension's own database on this computer; without it Chrome may refuse to save once the extension's storage is full. They can be deleted in settings.
  • tabCapture (optional): Never granted at install. Asked for the first time the user opens Record tab (“Record tab needs access to recording a tab”, Allow / Not now), then used only after the user presses Start recording, for the tab they chose. Chrome shows its sharing icon on the tab while recording; the video is saved only on the user's computer.
  • http://*/*, https://*/* (optional): Never granted at install. Asked for one site at a time, only by a Pro user who turns on Blur's auto-blur or Review pins' “Show pins automatically” for that site, so blurs or pins can appear as its pages load. Turning it off gives the access back; it's also listed and removable on the settings page.
  • https://api.gumroad.com/* (optional): Asked for only when the user activates a Pro license key, to check the key.
  • api.gumroad.com (asked only when you activate a key): to check your Pro license key.

Sharing and selling

Nothing is sold or shared. No data is used for advertising, credit or lending.

Children

Capture Studio isn't directed at children under 13 and collects nothing from anyone.
