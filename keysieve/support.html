Using KeySieve

I found a leaked key. What first?

Rotate it: make a new key with the provider and revoke the old one. Removing it from your code or history doesn’t help once it’s been pushed. Then take it out of the code, and, if you choose, remove it from history with git filter-repo (KeySieve shows the commands and the warnings).

Does it need git?

Yes, for history. It uses git from Apple’s command line developer tools or Homebrew. Plain folders without git are scanned too.

Will it find every secret?

No tool can promise that. KeySieve uses gitleaks’ 222 rules and reduces risk; it can’t guarantee.

How do I hide a false alarm?

Click Ignore… on the finding: KeySieve shows the exact line and adds it to .gitleaksignore at the top of the repository, which gitleaks reads too.

KeySieve Pro

What’s free, and what does Pro add?

Free: one repository, the files on disk, every finding with its fix steps, and the ignore list. Pro adds git history, any number of repositories, the pre-commit hook and PDF and CSV reports. It’s a one-time purchase on Gumroad, with no subscription.

Where do I enter my license key?

Choose KeySieve › Settings…, open the Pro tab, paste the key from your Gumroad receipt and click Activate.

How do I get updates?

KeySieve checks for updates on its own; you can also choose Check for Updates… from the KeySieve menu. Updates are free.
