Getting started

Where are my collections kept?

In the folder you choose: opencollection.yml for the collection, a folder.yml in each folder, one .yml file per request, and environments in environments/. Put the folder in your project’s Git repository to share it.

Why does Plainwire ask me to pick a folder?

Plainwire runs in Apple’s App Sandbox, so it can open only the folders you choose. Choose File › New Collection… to make one, or File › Open Collection Folder… for one you have. Plainwire remembers the folders you open.

Does it work with Bruno?

Yes. Plainwire reads and writes OpenCollection YAML in the layout Bruno 3 uses, so Bruno and its command-line runner open the same folder. It also opens .bru collections, read only; File › Convert to OpenCollection YAML… writes an editable copy into a new folder.

Moving from Paw or Postman

How do I move from Paw (RapidAPI for Mac)?

In Paw, choose File › Export › All Requests › OpenAPI 3.0 Generator (install the OpenAPI 3.0 Generator extension from Paw’s extensions page if it isn’t listed) and save the file. In Plainwire, choose File › Import › OpenAPI or Swagger (and Paw)…. The Moving from Paw guide in Plainwire’s Help menu has every step, and what to check afterwards: Paw’s exporter labels query parameters as headers, and it doesn’t export passwords or tokens, so add those in Collection Settings › Secrets.

How do I import from Postman?

In Postman, export the collection as Collection v2.1 and each environment as a file. In Plainwire, choose File › Import › Postman Collection… and Postman Environment…. Tokens and passwords in the export’s auth settings, credential headers and variables go to your Keychain, not the files. With Pro, most pm.test, pm.expect and pm.environment scripts run as they are.

Can I paste a cURL command?

Yes: Request › Paste cURL as New Request… (⇧⌘V). Request › Copy as cURL (⇧⌘C) goes the other way.

Secrets and scripts

Where do my passwords and tokens go?

To the Keychain on your Mac. The file gets a {{variable}} in their place, so each person who uses the collection adds their own values. This happens for auth fields, credential headers like Authorization and X-API-Key, and variables named like secrets.

Why did Plainwire ask before running scripts?

Scripts and tests in a collection run on your Mac when you send, and they can read your variables, secrets included. Plainwire asks once per collection folder, so you can choose Send Without Scripts for a collection you don’t trust.

Can I use a local server with a self-signed certificate?

Turn on Allow self-signed certificates on local servers in Plainwire’s Settings. It applies only to this Mac, local network addresses, and .local, .test and .internal names.

Plainwire Pro

What’s free, and what does Pro add?

Free: unlimited requests, history (up to 2,000 requests), one collection folder, every import and cURL export. Pro adds environments, scripts and tests, and more than one collection folder at a time. It’s a one-time purchase on Gumroad, with no subscription, and the license key works on up to 3 of your Macs.

Where do I enter my license key?

Choose Request › Plainwire Pro… (or Plainwire › Settings › Enter License Key…), paste the key from your Gumroad receipt and click Activate.

How do I get updates?

Plainwire checks for updates on its own; you can also choose Plainwire › Check for Updates…. Updates are free.
