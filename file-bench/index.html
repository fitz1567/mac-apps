File Bench privacy policy

Effective October 6, 2026

File Bench is a Chrome extension by Kevin Fitzgerald. It does not collect your data. There is no account, no analytics and no server of ours: what you save stays in your browser on this computer.

What it keeps on your computer

  • PDF pages: how to save files, and your last page-number and watermark choices
  • Fill & sign: date format and text color; with Pro, the signatures and initials you choose to save (as images) and your form templates
  • CSV viewer: export settings; with Pro, saved views (filters, sort, column layout) under each file's name
  • Compress images: format, quality and size; with Pro, your presets
  • Favicons: your last settings; with Pro, saved projects (settings and the source image)
  • Share images: the design you're editing (text, colors, fonts, any logo or photo you add); with Pro, saved designs and brand kits, and after you click "Use this page", that page's title, description, site name and icon in session storage that Chrome clears when it closes
  • QR codes: your style settings (colors, shape, logo); with Pro, saved designs
  • Audio trim: export format and bitrate, fade shape, silence and loudness settings, batch recipe
  • The tool you used last, and your license key, if you buy Pro

This lives in the browser's own extension storage. Removing the extension deletes it.

Network

File Bench has no server and never uploads your files: PDFs, images, audio and spreadsheets are opened, edited and saved inside your browser on this computer, and every tool works with no internet connection. When you pass a file from one tool to another, it waits in the extension's own database on this computer until the other tool opens it. QR codes are static: they hold your content directly and never route through a server. The only network request File Bench makes is checking a Pro license key with Gumroad, when you activate it and every two weeks.

Pro purchases

Pro is sold by Gumroad, which handles the payment and emails your license key. Gumroad's own privacy policy covers that purchase. When you activate a key, File Bench sends the key and File Bench's Gumroad product ID to Gumroad's license server (api.gumroad.com) to check it, and checks it again about every two weeks. Nothing else is sent.

Permissions

  • activeTab: Only when the user clicks the toolbar button (or presses Alt+Shift+O) on a tab: QR codes reads that tab's address to show a QR code for it, and Share images can read that tab's title, description, site name and icon when the user clicks "Use this page" (Pro). Only that tab, only after the click. No other page is ever read.
  • scripting: Runs one function in the tab the user opened File Bench on, once, when they click "Use this page" in Share images: it reads the page's <title>, its description and site-name meta tags and its icon, for the share image. Nothing else on the page is read and nothing is changed.
  • storage: Keeps each tool's settings on this computer: how to save PDFs, date format and (Pro) saved signatures and form templates, image presets, favicon projects, share-image designs and brand kits, QR styles and designs, CSV export settings and saved views, audio export settings, the last tool used, and the Pro license. Files themselves are never stored; a file passed from one tool to another waits in the extension's own browser database for a few seconds until the other tool opens it.
  • sidePanel: Lets the user keep File Bench open in Chrome's side panel and drop files from their computer on a tool there.
  • optional:https://api.gumroad.com/*: Asked for only when the user activates a Pro license key, to check the key.
  • content_security_policy (wasm-unsafe-eval): Not a permission. Chrome's default for extension pages, written out: the bundled PDF reader (pdf.js) decodes some image types (JPEG 2000, JBIG2) and color profiles, and Compress images makes AVIF files, with WebAssembly files that ship inside the extension. No code is fetched from anywhere.
  • api.gumroad.com (asked only when you activate a key): to check your Pro license key.

Sharing and selling

Nothing is sold or shared. No data is used for advertising, credit or lending.

Children

File Bench isn't directed at children under 13 and collects nothing from anyone.
