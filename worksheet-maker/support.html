Making worksheets

How do I print the same worksheet again?

Every worksheet has a number at the bottom of its pages. Type that number into Sheet number with the same grade, subject and skills, and you get the same questions again.

Why did I get fewer questions than I asked for?

A few skills have a set number of different questions (for example, reading skills with a fixed group of passages). Worksheet Maker never repeats a question on one sheet, so it prints all of them. The line under the preview tells you when this happens.

What does “Mix the skills together” do?

It shuffles the questions from all the skills you chose onto shared pages for a mixed review. Questions about a reading passage stay together, right under it. Turn it off to give each skill its own pages.

What paper size does it use?

US Letter (8.5 × 11 in). On A4 paper, macOS scales each page to fit.

Using the worksheets

Can I copy the worksheets for my class?

Yes. Print as many copies as you like for your own students or children.

Where do the questions come from?

From the Learning Adventure learning games for Kindergarten through 8th grade: the same question makers, checked by thousands of automated runs for one correct answer each.
